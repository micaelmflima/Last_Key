# Versão antiga — apenas para histórico

**O jogo atualizado está na branch `main`, em [`public/index.html`](../public/index.html).**

O arquivo `Last_Key_1.0.0_ANTIGO.zip` é o primeiro pacote recebido, anteriormente
chamado `last-key.zip`. Seu conteúdo foi preservado integralmente. Ele não inclui
as atualizações posteriores de sprites, animações, novas áreas, habilidades e desempenho.

Para jogar ou desenvolver a versão mais nova, siga o [README principal](../README.md)
e baixe o projeto completo pela opção **Code → Download ZIP**.
